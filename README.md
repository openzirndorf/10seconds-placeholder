# 10seconds-placeholder

Platzhalter-Seite für **10sekunden.openzirndorf.de**.

Die Seite gehörte zur Mitmach-Aktion „10 Sekunden“ von OpenZirndorf e.V. am
18.10.2026 (Uhr starten, blind bei exakt 10,000 s stoppen). Die Aktion ist
vorbei; die Seite besteht weiter zum Üben.

- `index.html` – Info zur Aktion + Endstand (nur Platz, Nickname, Zeit)
- `ueben.html` – Übungsmodus, rein im Browser (kein Server, keine Datenübertragung)
- `impressum.html` – Impressum & Datenschutz

Rein statisch (GitHub Pages), keine externen Abhängigkeiten, keine Zugangsdaten.
